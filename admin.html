Portfolio Data Helper

Use this page locally to prepare new project entries for `works-data.js`.

How to use

  • Fill the project details in the form.
  • Copy the generated JSON object.
  • Paste it inside the array in works-data.js.
  • Upload the matching image into assets/works.

This helper is intentionally public-safe and does not contain login credentials.
