Paneli ya kuongeza na kuchapisha kazi

Paneli hufanya kazi kwenye kompyuta yenye Git workspace yako. Fungua repo ndani ya VS Code, endesha npm run admin, kisha nenda http://127.0.0.1:4178/admin.html.

Kitufe cha kuchapisha hutengeneza commit ya kazi na kusukuma kwenye branch ya sasa ya Git. Git Credential Manager ndiyo hushughulikia login yako ya GitHub; usiweke tokeni au nenosiri kwenye tovuti.
